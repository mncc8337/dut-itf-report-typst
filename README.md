# dut-itf-report-typst
dut itf report paper typst template. other faculty can adapt by changing the `faculty` and `logo` field.


edit `main.typ` directly. the template layout is already there


itf logo (`template/faculty-logo.jpg`) taken from [https://www.facebook.com/photo/?fbid=731780863568022](https://www.facebook.com/photo/?fbid=731780863568022). no svg found sadly, this is the highest res i could find.

## compile
```sh
typst compile main.typ report.pdf
```
